# umkim-thin 0.3.7

A dark-mode contrast fix in the console's catalog install form.

## Fixed

- **Catalog → Install → Advanced** is readable in dark mode. The panel used a
  hard-coded light background (`#fbfcfe`) while the dark theme's text colour is
  light, so the summary was light grey on white. The background now follows the
  theme: `#fbfcfe` in light mode and `#1a2431` in dark mode, matching the other
  inset panels.
- The inline `background` and `summary` styles were moved into the stylesheet so
  a theme cannot be overridden by a hard-coded value again.

## Compatibility and upgrade safety

No console state, database, catalog or chart migrations. The console image
changes only; rebuild it with the usual installer.

Single node:

```bash
git fetch --tags
git checkout v0.3.7
git submodule update --init --recursive
sudo ./install.sh --reuse-k3s
```

Provisioned/HA cluster (on the jumphost, prefix with `CI_ON_JUMP=1`):

```bash
git fetch --tags
git checkout v0.3.7
git submodule update --init --recursive
PROVISION_ENV=deploy/provision-ha.env ./deploy/provision.sh
```
