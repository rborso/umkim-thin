# umkim-thin 0.3.23

Patch release: Miniflux SSO could never complete, because the console dropped a
chart value it had just been given.

## Fixed

**`applyOIDCValues` replaced the app's `oidc` values instead of merging into them.**
For any app without a dedicated case it did

```go
set(values, "oidc", map[string]any{ "enabled": …, "clientId": …, … })
```

which discards everything the catalog had placed under `oidc.*`. Miniflux's chart
reads `oidc.redirectUrl` to build `OAUTH2_REDIRECT_URL`; after the replace that
variable was **empty**, so Miniflux sent an authorize request with no
`redirect_uri` and Authelia rejected it:

```
400 invalid_request
The 'redirect_uri' parameter is required when using OpenID Connect 1.0.
```

The login page still offered "Sign in with Directory", the client was registered
correctly, and the route was fine - so every surface-level check passed while the
SSO round trip was impossible.

The `default` branch now merges: the generated client wins, and any chart-specific
field the catalog set survives.

## How it was found

The first Miniflux gate run showed 83 passed with one failure - the OIDC flow -
while the tenant API check passed. Tracing the network showed the click on the SSO
link returning `302 -> 400` on Authelia's authorize endpoint. The 400 body named
the missing parameter, and `env` inside the pod showed `OAUTH2_REDIRECT_URL=` empty
next to a populated `OAUTH2_CLIENT_ID`.

`docs/apps/testing.md` is the reason this did not ship silently: the entry claimed
`oidc_sso_completes`, that claim resolves to a real gating test, and the test
failed.

## Tests

`TestApplyOIDCValuesKeepsChartSpecificFields` and
`TestApplyOIDCValuesCreatesTheMapWhenAbsent`. The first fails against the previous
code with `redirectUrl = <nil>`, which is the same value the cluster had.

## Note

This affects any future app whose chart takes OIDC fields beyond the four the
console sets - the dedicated cases (immich, paperless, gitea, nextcloud,
vaultwarden) were never at risk because they set their own complete maps.
