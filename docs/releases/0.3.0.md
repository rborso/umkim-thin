## Notable changes

- Jellyfin 12.4 with the LDAP plugin v24. The startup/auth/API-key routes used
  by the bootstrap remain; the bootstrap, markers and auth spec also send the
  standard `Authorization: MediaBrowser` header that Jellyfin 12 requires when
  legacy authorization is off. Jellyfin's config volume is now 3 GiB (12 needs
  2 GiB free); an existing 2 GiB claim must be expanded before the upgrade.
- Radarr 6.4, qBittorrent 5.3, Sonarr 4.0.20 and Prowlarr 2.7. qBittorrent 5.3
  uses the `[WebUI]` credential layout and returns 204/JSON API responses; the
  chart init and the CI checks handle both.
- Mealie 3.30 with an `extraEnv` passthrough (`HTTP_ALLOW_LIST` for private
  network imports when needed).
- Immich server and ML images are exact `v3.3.5` pins instead of `release`.
- Valkey 9.1.3 and Alpine 3.24.3 replace the EOL Alpine 3.20 images.

## Upgrading

Single node:

```bash
git pull
sudo ./install.sh --reuse-k3s
```

Provisioned/HA cluster: run the provisioner with the target environment, after
a backup. The platform updater rebuilds/re-imports the console image and keeps
the app data. App upgrades can then be selected explicitly in **Applications**.
