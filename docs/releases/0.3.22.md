# umkim-thin 0.3.22

Adds **Miniflux** (RSS/Atom reader) to the catalog, and bumps the catalog to 0.1.7.

## The app

`miniflux` 0.1.0, appVersion 2.3.5, chart in `umkim-charts` at `a625981`:

- PostgreSQL-backed, no data volume of its own.
- OIDC through Authelia; the redirect URI is Miniflux's documented
  `/oauth2/oidc/callback`.
- `route miniflux.{{ .zone }}`, 2Gi PostgreSQL volume.
- Fits the single-node budget: 64Mi request for the app, 128Mi for PostgreSQL.

## It went through the pipeline, not around it

This is the first app added since the test-category work in 0.3.21, so the claims
are checkable:

| Check | Carried by |
|---|---|
| `route_reachable`, `authenticated_request_reaches_app` | `apps.spec.ts` (gate) |
| `oidc_sso_completes` | `auth.spec.ts` (gate) |
| `tenant_api_miniflux` | `journeys/tenant.spec.ts` (gate) - an invited tenant reads `/v1/me` |

`docs/apps/testing.md` lists it as auto-tested with those four checks resolved to
real tests. There is no human log yet, so no "verified" badge - which is the point
of deriving the category rather than assigning it.

## Proving the chart before publishing it

A chart that only `helm lint`s is not known to work, so it was installed on the HA
lab target first:

- both pods Running on the first attempt;
- `/healthcheck` returns `OK`; migrations applied to version 135; the admin
  account created;
- `/v1/me` returns 200 with the admin identity through a port-forward;
- with OIDC enabled, the login page serves the "Directory" SSO link and its
  callback returns a redirect rather than an error.

The test install and the OIDC client it added to the identity release were removed
afterwards; ha-dev is back to 0 unhealthy pods with no miniflux client left behind.

## One guard changed

`ci/check-mirror-versions.py` required an N-1 tarball for every app chart. A chart
on its **first** release has nothing to roll back to, so the requirement is now
skipped when the catalog lists a single version for that chart. The exemption is
narrow: dropping an established chart's N-1, or a two-version chart's N-1, still
fails - both verified.
